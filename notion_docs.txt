MAIA Router — API Quick Start
Quick Start
Get started with MAIA Router in minutes. Create an API key, then call a model from your app.
Create an API Key
Go to "API Keys" and add a new key. Keep it secret. Go to API Keys
Call a model (JavaScript with OpenAI SDK)
Replace YOUR_API_KEY with the key you created.
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'YOUR_API_KEY',
  baseURL: 'https://api.maiarouter.ai/v1'
});

const completion = await client.chat.completions.create({
  model: 'maia/gemini-2.5-flash',
  messages: [
    { role: 'user', content: 'Hello MAIA!' }
  ]
});

console.log(completion.choices[0].message.content);

​
Call a model (Python with OpenAI SDK)
Install the OpenAI Python library first:
pip install openai
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.maiarouter.ai/v1"
)

completion = client.chat.completions.create(
    model="maia/gemini-2.5-flash",
    messages=[
        {"role": "user", "content": "Hello MAIA!"}
    ]
)

print(completion.choices[0].message.content)

Call a model (cURL)
Quick test from your terminal.
curl https://api.maiarouter.ai/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "maia/gemini-2.5-flash",
    "messages": [
      {
        "role": "user",
        "content": "Hello MAIA!"
      }
    ]
  }'

API Endpoints
Base URL : 
 https://api.maiarouter.ai/v1

​
Chat Completions : 
https://api.maiarouter.ai/v1/chat/completion

​
Videos (Sora 2) : 
Create video: 
Endpoint :
POST https://api.maiarouter.ai/v1/videos

​
cURL Example :
curl --location 'https://api.maiarouter.ai/v1/videos' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer sk-123' \
--data '{
    "model": "sora-2",
    "prompt": "A beautiful sunset over the ocean"
}'

​
Remix video : 
Endpoint :
POST https://api.maiarouter.ai/v1/videos/video_id/remix

​
cURL Example :
curl --location --request POST 'https://api.maiarouter.ai/v1/videos/video_id/remix' \
--header 'Accept: application/json' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer sk-123' \
--data '{
    "prompt": "New remix instructions"
}'

​
Retrieve video:
Endpoint: 
GET https://api.maiarouter.ai/v1/videos/{video_id}

​
cURL Example :
curl --location 'https://api.maiarouter.ai/v1/videos/video_id' \
--header 'Accept: application/json' \
--header 'Authorization: Bearer sk-123'

​
Retrieve video content :
Endpoint : 
GET https://api.maiarouter.ai/v1/videos/video_id/content

​
cURL Example :
curl --location 'https://api.maiarouter.ai/v1/videos/video_id/content' \
--header 'Accept: application/json' \
--header 'Authorization: Bearer sk-123' \
--output video.mp4

Videos (Veo 3.1) : 
Endpoint Request: 
POST https://api.maiarouter.ai/vertex_ai/publishers/google/models/{{Models-Change-Here}}:predictLongRunning

​
cURL Example Request:
curl -X POST --location "https://api.maiarouter.ai/vertex_ai/publishers/google/models/{{models-change-here}}:predictLongRunning" \
-H "Authorization: Bearer sk-123" \
-H "Content-Type: application/json" \
  -d '{
    "instances": [{
      "prompt": "A cat playing with a ball of yarn in a sunny garden"
    }],
    "parameters": {
      "storageUri": "gs://maiarouter/",
      "sampleCount": "1",
      "duration":"1s"
    }
  }'

​
Example Response :
{
    "name": "projects/learned-nimbus-473801-q8/locations/global/publishers/google/models/veo-3.0-generate-001/operations/7087d016-fd23-49c4-9964-e458b2d13bb8"
}

Endpoint fetchPredictOperation:
https://api.maiarouter.ai/vertex_ai/publishers/google/models/{{Model}}:fetchPredictOperation

​
cURL Example :
curl --location 'https://api.maiarouter.ai/vertex_ai/publishers/google/models/veo-3.0-generate-001:fetchPredictOperation' \
--header 'Content-Type: application/json' \
--header 'x-litellm-api-key: sk-123' \

OpenAI (GPT-Image-1)
Create Image
Endpoint : 
POST https://api.maiarouter.ai/v1/images/generations

​
cURL Example :
curl -s -X POST https://api.maiarouter.ai/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-123"" \
  -d '{
    "model": "'"$MODEL"'",
    "messages": [{"role": "user", "content": "Generate an image of a cat"}]
  }'

​
Edit Image
Endpoint : 
https://api.maiarouter.ai/v1/images/edits

​
curl --location 'https://api.maiarouter.ai/v1/images/edits' \
--header 'Authorization: Bearer sk-123"' \
--form 'model="openai/gpt-image-1"' \
--form 'image=@/path/to/original.png' \
--form 'mask=@/path/to/mask.png' \
--form 'prompt="Add a cat sitting on the chair, realistic lighting, 4k resolution"' \
--form 'size="1024x1024"'
